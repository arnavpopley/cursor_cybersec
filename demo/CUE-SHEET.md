# Timed cue sheet (for the editor / recorder)

Use with `demo/voiceover-script.txt`. Approximate cue points if your TTS
output lands near 1:45.

| Cue | Voiceover line starts… | Cut / zoom |
|-----|-------------------------|------------|
| 0:00 | “This is Keyring…” | Brand header |
| 0:08 | “We load Acme’s account file…” | Findings populate |
| 0:22 | “Here is the headline risk…” | Expand CRITICAL / Marco chain |
| 0:42 | “Ask in plain English…” | Ask + citation expand |
| 0:58 | “When we apply a fix…” | Apply → NFC banner |
| 1:15 | “Tap. The fix applies…” | Tap or Ctrl+Shift+A; audit |
| 1:28 | “A voice agent can explain…” | Voice button / audit strip |
| 1:38 | “Keyring: analyze access paths…” | Hold brand; end |

Word count of voiceover-script.txt is intentionally ~245 words for ~105s
at ~140 words per minute. If your TTS runs fast, add short pauses in the
model settings (stability / style) rather than rewriting.
